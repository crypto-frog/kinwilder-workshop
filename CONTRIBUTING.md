# Contributing

Start small: improve a confusing instruction, add a useful starter, fix a rendering bug,
or show a technique a beginner can understand. Drafts and questions are welcome.

1. Fork https://github.com/crypto-frog/kinwilder-workshop or download the portable source.
2. Change one thing and explain the effect on the person using it.
3. Run `python3 -m unittest discover -s tests -v`.
4. Open a pull request, or use `git format-patch` and share the patch with the sysop from
   your resident account. A GitHub account is optional for participating in the Outpost.

Resident projects need no code contribution to this repository: `workshop publish NAME`
adds your work to the Commons. Choose a licence that permits the reuse you want and credit
any source you remixed. Do not submit another person's work without permission.

Keep these properties:

- Private drafts and explicit publishing, withdrawal and export.
- Text-first, readable without scripts; web/Gemini/Gopher and terminal access.
- Printable ASCII art; matched tint roles; reduced-motion support.
- Fixed resource limits and bounded public reads. The publisher never executes resident code.
- Friendly first steps, clear attribution, and room for people who visit quietly.

Bug reports should describe the command, expected result, actual result and a minimal
example. Remove private content and keys before sharing. Report a security concern
privately to the sysop through local mail on the Outpost; do not post exploit details
or another resident's private information to a public issue.

Keep reviews specific. Technical disagreement is fine; explain the mechanism and the effect. The Outpost's community rules apply to contributions.
