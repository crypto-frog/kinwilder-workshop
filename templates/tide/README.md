# Your Kinwilder Workshop project

This folder is private until you run workshop publish NAME.
Edit the text frames or note.txt, then edit the title and summary in outpost.json.
Run workshop check NAME before sharing.

The example is provided under the Workshop's MIT licence. Your publication defaults
to All rights reserved. Choose your own licence deliberately in outpost.json:
All rights reserved, CC0-1.0, CC-BY-4.0, or MIT.
Credit the source and author of any permitted remix.

Publishing copies outpost.json and only the files listed in its files array.
Those selected files also go into a downloadable source.zip; review them first.
It does not publish your home folder, dotfiles or Git history.
To withdraw: workshop withdraw NAME (shared pages clear within two minutes).
To keep a private portable copy: workshop pack NAME.
The server currently makes no off-server backup promise. Keep your own copies.

Try changing the ripple groups; leave open water between them.
